## Contained in this repository

Nothing third-party is vendored. In particular, the repository contains **no** model weights, no COCO or
Cityscapes images or annotations, no NVIDIA headers or libraries, and no profiler output. The tracked files that refer to
third-party data are:

| file | content | origin |
|---|---|---|
| `configs/references/coco-val2017-first*.yolox-*-coco-v1.gpu-capture.golden.jsonl` | COCO image ids and SHA-256 digests of SDV-BMT's own encoded detection outputs | produced by SDV-BMT runs |
| `configs/workloads/yolox-*-coco-v1*.yaml` | SHA-256 of the YOLOX ONNX files (Tiny, S, M, L, X) and of the derived plan/weights | digests only |
| `configs/inputs/coco-val2017-first*.yaml` | SHA-256 of the locally built COCO subset index | digests only |
| `configs/workloads/deeplabv3plus-*-cityscapes-v1.yaml`, `configs/duts/*-deeplabv3plus-*.yaml` | SHA-256 of the locally exported DeepLabV3+ ONNX files and derived plans/weights; cuDNN algorithm tables | digests and enum values only |
| `configs/experiments/deeplabv3plus-*.yaml` | experiment settings that reference a locally built Cityscapes val input (not in this repository) | no Cityscapes data |
| `configs/inputs/cityscapes-val500.yaml` | SHA-256 of the locally built Cityscapes val index (images and ground truth stay local) | digests only |
| `configs/references/cityscapes-val500.deeplabv3plus-*-cityscapes-v1.gpu-capture.golden.jsonl` | Cityscapes val image names and SHA-256 digests of SDV-BMT's own encoded label maps | produced by SDV-BMT runs; no Cityscapes pixels or labels |
| `configs/fixtures/reference-images-v1*.index.jsonl` | synthetic test images (gradients, rings, stripes, noise) | generated by `tools/stage1r_g/build_reference_assets.py` |

## NVIDIA reference backend (optional; installed by the user, not distributed)

The NVIDIA native runner (`make -C native`, target `build/sdv-bmt-native-nvidia`) compiles against headers of
the installed CUDA toolkit and links the installed driver libraries and cuDNN. None of these is part of this
repository.

| component | version used for the v0.1.0 and v0.1.2 reference evidence | license (declared) |
|---|---|---|
| CUDA Toolkit headers, NVRTC, CUDA driver API, NVML | CUDA 13.0, driver 580.119.02 | NVIDIA CUDA Toolkit EULA / NVIDIA driver license |
| cuDNN (pip package `nvidia-cudnn-cu12`) | 9.1.0.70 | NVIDIA proprietary software license |
| Nsight Systems (optional profiler cross-check) | 2025.3.2 | NVIDIA software license |
